🏨 Hotel Booking Analysis and Customer Analystis System
 
## Project Overview
 
This project focuses on analyzing hotel booking data to generate meaningful business insights related to booking trends, customer behavior, cancellation rates, revenue performance, and discount recommendations.
 
The dataset was collected from Kaggle and processed using Python, NumPy, and Pandas for data cleaning and preprocessing. The cleaned dataset was then loaded into MySQL for data storage and analysis. SQL queries were used to extract insights, and Tableau was used to create interactive dashboards.

## Key Insights
 
- City Hotel generated more bookings than Resort Hotel.
- Online bookings contributed the highest share.
- Double rooms were the most preferred room type.
- New Guests represented the largest customer segment.
- Repeat Guests were identified for loyalty discount programs.
- High-value customer segments were identified using ADR analysis.
 
---
 
## Business Recommendations
 
- Offer 20% discounts to Repeat Guests.
- Offer 10% welcome discounts to New Guests.
- Provide loyalty rewards to high-value customers.
- Introduce seasonal promotions for Group customers.
- Run country-specific marketing campaigns.
